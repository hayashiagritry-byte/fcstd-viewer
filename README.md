# FCStd ビューワー

FreeCADのファイル(.FCStd)をiPadやスマホのブラウザでそのまま表示するビューワーです。
開いたファイルは閲覧者の端末のブラウザ内だけで処理され、サーバーには送信されません。

## ファイル構成

| ファイル | 内容 |
|---|---|
| index.html | ビューワー本体 |
| occt-import-js.wasm | 形状エンジン(OpenCascade)。index.html と同じ場所に置いてください |
| icon.png | ホーム画面に追加したときのアイコン |
| LICENSE-*.txt | 形状エンジンのライセンス(LGPL)。削除せず一緒に置いてください |

## GitHub Pagesでの公開手順

1. GitHubにログインし、右上の「+」→「New repository」で新しいリポジトリを作る
   - 名前の例: `fcstd-viewer`
   - 公開設定は **Public**(無料プランでPagesを使う場合)
2. 作成後の画面で「uploading an existing file」を押し、このフォルダの中身をすべてドラッグ&ドロップして「Commit changes」
   - occt-import-js.wasm は約7.7MBです。ブラウザからのアップロード上限(25MB)内なのでそのまま上げられます
3. リポジトリの「Settings」→ 左メニュー「Pages」を開く
4. 「Build and deployment」の Source を **Deploy from a branch**、Branch を **main** / **(root)** にして「Save」
5. 1〜2分待つと、同じ画面の上部に公開URLが表示されます
   - 例: `https://<ユーザー名>.github.io/fcstd-viewer/`

## 使い方(渡す相手向け)

1. iPadのSafariで公開URLを開く
2. 共有ボタン →「ホーム画面に追加」でアプリのように使えます
3. ツールバーのフォルダのボタン(開く)から、ファイルアプリ(iCloud Drive等)の .FCStd を選ぶ

- iPad: 1本指で回転、2本指でズーム・移動、タップで部品を選択
- マウス: ホイールを押したままドラッグで回転、右ドラッグで移動、ホイールで拡大縮小、左クリックで選択
- ツールバー: 開く、部品パネル、全体表示、視点切替、断面、2点間の距離計測、表示モード、設定
- 部品パネル: ふだんは「すべて」だけ。「一覧」ボタンで部品ごと・グループごとの表示切替
- 各パネルは左端の点々をドラッグして移動、右下の角で大きさ変更。ツールバーは画面の端へ運ぶとその辺に収まります(設定から上・下・左・右・自由も選べます)
- 開閉: 部品に動き方(Motion)が書かれたファイルでは、ツールバーに「開閉」ボタンが出ます。ふだんは「すべて」だけ、「一覧」で引き出し・扉を1か所ずつ開閉。開閉パネルを開いている間は、3Dの部品をタップするとそこだけ開閉します(書式は MOTION_SPEC.md)
- FreeCAD 1.0以降で外観に画像(テクスチャ)を設定した部品は、画像も表示されます

## 木目・天板の画像(家具CADのファイル)

家具CADで作ったFCStdは、木目や天板の画像をファイルの中に持たず、パソコン上の画像(例: `C:\Users\...\VWscript\materials\textures\shina_color.png`)を参照しています。
ビューワーで表示するには、どちらかの方法で画像を用意します。

1. **みんなに見せる場合**: このリポジトリに `textures` フォルダを作り、画像(shina_color.png など)をそのまま入れる。ファイル名で自動的に探します
2. **自分の端末だけで見る場合**: 「詳細」→「画像を読み込む」で画像を選ぶ。その端末に記憶されます

画像が無い部品は、FreeCADで設定した色で表示されます。

## 注意

- 表示用のライブラリ(three.js、JSZip、occt-import-js)をインターネットのCDNから読み込むため、使用時はネット接続が必要です
- スケッチのみのファイル、外部ファイルへのリンクは表示できません
