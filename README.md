# FCStd ビューワー

FreeCADのファイル(.FCStd)をiPadやスマホのブラウザでそのまま表示するビューワーです。
開いたファイルは閲覧者の端末のブラウザ内だけで処理され、サーバーには送信されません。

## ファイル構成

| ファイル | 内容 |
|---|---|
| index.html | ビューワー本体 |
| occt-import-js.wasm | 形状エンジン(OpenCascade)。index.html と同じ場所に置いてください |
| icon.png | ホーム画面に追加したときのアイコン |
| LICENSE-*.txt | 形状エンジンのライセンス(LGPL)。削除せず一緒に置いてください |
| MOTION_SPEC.md | 開閉の動き方データの書式(CAD 側でデータを作る人向け) |

## GitHub Pagesでの公開手順

1. GitHubにログインし、右上の「+」→「New repository」で新しいリポジトリを作る
   - 名前の例: `fcstd-viewer`
   - 公開設定は **Public**(無料プランでPagesを使う場合)
2. 作成後の画面で「uploading an existing file」を押し、このフォルダの中身をすべてドラッグ&ドロップして「Commit changes」
   - occt-import-js.wasm は約7.7MBです。ブラウザからのアップロード上限(25MB)内なのでそのまま上げられます
3. リポジトリの「Settings」→ 左メニュー「Pages」を開く
4. 「Build and deployment」の Source を **Deploy from a branch**、Branch を **main** / **(root)** にして「Save」
5. 1〜2分待つと、同じ画面の上部に公開URLが表示されます
   - 例: `https://<ユーザー名>.github.io/fcstd-viewer/`

## 使い方(渡す相手向け)

1. iPadのSafariで公開URLを開く
2. 共有ボタン →「ホーム画面に追加」でアプリのように使えます
3. 右上の「FCStdを開く」から、ファイルアプリ(iCloud Drive等)の .FCStd を選ぶ

- 1本指: 回転 / 2本指: ズーム・移動 / タップ: 部品を選択
- 下のツールバー: 全体表示、視点切替、断面、2点間の距離計測、表示モード切替
- 「開閉」ボタン(動く部品があるときだけ出ます): 引出し・扉などを 1 か所ずつ、または「すべて」まとめて開閉する

## 開閉(引出し・扉など)

部品の中に「動き方」のデータ(プロパティ `Motion`)が書き込まれていれば、その動きを再現します。
ビューワーは部品の種類を知らなくても動かせるので、**新しい動く部品を作ってもビューワーを直す必要はありません。**
書き方は [MOTION_SPEC.md](MOTION_SPEC.md) を見てください。

- 動きは 2 種類: まっすぐ動く(引出し・スライドレール) / 軸のまわりに回る(扉)
- 1 つの部品に複数の動きを書ける(例: 引出しと扉)。面ごとに倍率を付けられる(例: レールの中間部材は半分)
- 開閉は 1 か所ずつできる: 「開閉」パネルに、部品と動き(例:「キャビネット・扉」)の一覧が出て、それぞれにスライダーと「開く/閉じる」ボタンがある
- パネルを開いているときは、3D の部品をタップすると、タップした所(扉なら扉、引出しなら引出し)だけ開閉する
- 一覧の上の「すべて」で、全部を同じ開き具合にまとめて動かせる(開き具合がそろっていないときは「ばらばら」と表示)
- それぞれ、ファイルに保存された状態から始まる。開き具合は 0〜100 %(mm や度も表示)
- 部品を回転・移動して配置していても、App::Part の中に入れていても、部品の向きどおりに動く
- 動きの入れ子(動く箱の中で動く引出し)はできない

互換: 家具CAD の試作版で作ったワイヤーシェルフII・フレームバスケットII は、`Motion` が無くても、
部品の種類(furniture.wire_shelf / furniture.frame_basket)と形の並び順から動きを作ります(index.html の `LEGACY_MOTIONS`)。

test フォルダ: 確認用のファイルと、それを作る FreeCAD のスクリプト(make_samples*.py)。公開するときは上げなくて構いません。
- motion_cabinet_door_drawer.FCStd: `Motion` を書いた例(引出し 0〜400 mm と扉 0〜110° のキャビネット。回転して配置)
- motion_wire_shelf_spec.FCStd: ワイヤーシェルフに `Motion` を書いた例
- wire_shelf_*.FCStd / frame_basket_*.FCStd: `Motion` の無い試作版のファイル(互換の確認用)

## 注意

- 表示用のライブラリ(three.js、JSZip、occt-import-js)をインターネットのCDNから読み込むため、使用時はネット接続が必要です
- スケッチのみのファイル、外部ファイルへのリンクは表示できません
